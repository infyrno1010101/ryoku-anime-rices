# Demon Slayer — Musical Score Inferno

A native Ryoku rice grounded in the Entertainment District climax and Episode 10, **Never Give Up**: Sound Hashira Tengen Uzui and Tanjiro's final coordinated battle against Upper Six Gyutaro and Daki.

## Desktop direction

- 10-second 1920×1080 H.264 live wallpaper at 24 FPS
- Tengen–Gyutaro confrontation and charge layers
- Musical Score Technique rings and rhythm telemetry
- Dual Nichirin blade crescents
- Serpentine Blood Demon Art trajectories
- Gem-chain waveform, lantern sparks, impact shake, and flash cuts
- Top fit-style animated/frosted bar
- Right autohide dock
- Orbital 88-bar visualizer with score rotation
- Fixed gold, cyan, crimson, wisteria, and ink palette across terminal/apps
- Animated borders, gold glow, blur, dimming, impact focus, and dynamic cursor
- Holy Panda key sounds
- Custom Demon Slayer Fastfetch
- Calendar desktop widget disabled

## Separate custom lockscreen

`demon-slayer-wisteria-blood-moon` uses a distinct 12-second Tanjiro–Nezuko wisteria sanctuary—not the battle wallpaper. It includes falling petals, moon/breathing rings, mist, a vertical title seal, breathing waveform, shoji authentication altar, Nichirin password line, and Hinokami slash unlock animation.

## Install from this directory

Install the bundled lockscreen before applying the rice:

```bash
mkdir -p ~/.local/share/qylock/themes
cp -a lockscreen/demon-slayer-wisteria-blood-moon ~/.local/share/qylock/themes/
```

Then apply:

```bash
ryoku-hub rice preflight demon-slayer-musical-score-inferno
ryoku-hub rice apply demon-slayer-musical-score-inferno
```

## Ryoku Kasane

Kasane discovers the rice automatically when this directory is installed beneath `~/.config/ryoku/rices/`. Select **Demon Slayer — Musical Score Inferno**, press **Preview**, then **Apply Layer**. **Roll Back** restores the previous rice.
