# Lock, Stock and Two Smoking Barrels — Debt Domino

A native Ryoku rice based on Eddie's rigged £500,000 card debt and the chain reaction connecting the neighboring robbery, cash, cannabis, and two priceless antique shotguns.

## Desktop
- 10-second 1920×1080 H.264 animated wallpaper at 24 FPS
- Verified widescreen four-protagonist card/cash hero, East End alley freeze frames, rotating card orbit, climbing debt counter, intersecting heist routes, shotgun rails, and Guy Ritchie freeze-frame contrast
- Bottom fit brass ledger bar; left autohide dock
- Evidence-bar visualizer, green felt/brass/blood palette, animated borders/glow/blur
- Topre key sounds; custom Fastfetch; calendar disabled

## Separate lockscreen
`lock-stock-antique-evidence` is a distinct 12-second green-felt evidence table with procedural twin shotgun silhouettes, brass dial, exhibits, card-code authentication, and shuffle unlock wipe.

## Install lockscreen
```bash
mkdir -p ~/.local/share/qylock/themes
cp -a lockscreen/lock-stock-antique-evidence ~/.local/share/qylock/themes/
```

## Apply
```bash
ryoku-hub rice preflight lock-stock-debt-domino
ryoku-hub rice apply lock-stock-debt-domino
```
Kasane discovers it automatically as a NATIVE rice. Recovery: `ryoku-hub rice apply pre-crime-cinema-baseline`.
