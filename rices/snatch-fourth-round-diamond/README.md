# Snatch — Fourth Round Diamond

A native Ryoku rice based on Mickey O'Neil's fourth-round refusal to stay down, his revenge on Brick Top, and the stolen diamond that eventually passes through a dog.

## Desktop
- 10-second 1920×1080 H.264 animated wallpaper at 24 FPS
- Actual three-act final-fight sequence—Mickey underwater, suspended above the ropes, then standing again—plus ring ropes, fourth-round counter, impact flashes, rotating diamond, and dog-track path
- Top islands bar; right autohide dock
- Orbital diamond visualizer, cold-steel/gold palette, animated borders/glow/blur
- Holy Panda key sounds; custom Fastfetch; calendar disabled

## Separate lockscreen
`snatch-diamond-vault` is a distinct 12-second procedural black-velvet vault: rotating 84-carat diamond, safe dial, pawprint orbit, compact holder terminal, and jewel-burst unlock.

## Install lockscreen
```bash
mkdir -p ~/.local/share/qylock/themes
cp -a lockscreen/snatch-diamond-vault ~/.local/share/qylock/themes/
```

## Apply
```bash
ryoku-hub rice preflight snatch-fourth-round-diamond
ryoku-hub rice apply snatch-fourth-round-diamond
```
Kasane discovers it automatically as a NATIVE rice. Recovery: `ryoku-hub rice apply pre-crime-cinema-baseline`.
